Pre-Requisites for Local Hosting:
1. The ZIP file of this repository
2. XAMPP (Latest Version: 8.5.12)

How to Download the ZIP File?
1. Open https://github.com/Neonathixx/HLB-Portfolio and click the arrow beside the Code button.
2. Click on "Download ZIP".
3. Choose the destination folder and click "Save".
4. Extract the .zip file to your desired destination

How to Download XAMPP?
1. Go to https://www.apachefriends.org/download.html. You will be directed to the download page for XAMPP.
2. Click "Download" on the latest version which is 8.5.12. (For macOS users, XAMPP has a native downloader.) An .exe file will be downloaded. 
3. Run the .exe file once downloaded. It is the installer for XAMPP.
4. Click "OK" if any popup of UAC shows up.
5. Click 'Next' through setup prompts.
6. Choose your destination folder and click 'Next'
7. Select the language and click 'Next' to start the installation. 
8. If "Do you want to start the control panel now?" shows up, you can click "Finish".

Instructions for Local Hosting:
1. Open XAMPP
2. Switch on Apache and MySQL.
3. Click "Explorer" and go to htdocs.
4. Copy all the extracted files from its directory to htdocs.
5. Open Microsoft Edge or Google Chrome.
6. Type localhost/phpmyadmin.
7. Click the "New" tab on the left sidebar.
8. Click "Import" on the top bar.
9. Click "Choose File", open the "sql db" folder, and choose the "install_local.sql" file.
10. Scroll down and click "go".
